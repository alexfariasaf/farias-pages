01
Cena 01 · Fundamento 4 min

IDE ou CLI? A pergunta que organiza tudo.

+

Antes de decorar nome de ferramenta, entenda a diferença que vale por dez. Pense assim, com uma imagem do seu próprio mundo: a CLI é o despacho protocolado no balcão do fórum — rápido, seco, direto, sem cerimônia. A IDE é a sala de reunião do escritório — mesa grande, monitores, quadro branco, tudo à vista. Os dois resolvem problemas; o que muda é a postura de trabalho.

CLI · Linha de comando

O balcão do fórum

"Protocolo o despacho e sigo."
  • Você conversa por texto, no terminal
  • Enxuta — vai direto ao ponto
  • Ideal para repetição e automação
  • Consome menos recursos
IDE · Ambiente integrado

A sala de reunião

"Tudo na mesa, todos à volta."
  • Aplicativo gráfico: editor, abas, arquivos
  • Você VÊ telas e arquivos mudando
  • Vários assistentes em paralelo
  • Consome mais — visibilidade tem custo

Use CLI quando a tarefa é repetível e você já sabe o resultado. Use IDE quando precisa ver o que está acontecendo ou começar algo do zero.

02
Cena 02 · Os três sistemas 4 min

Três ferramentas, três naturezas diferentes.

+

A confusão mais comum é achar que tudo é "IDE". Não é. Só uma das três é um IDE de verdade. As outras duas nascem no terminal e ganham uma extensão para entrar num editor — não existe um aplicativo "Claude Code IDE".

IDE Completo

Antigravity

Google

Aplicativo próprio. Acessa vários modelos pela assinatura do Google. Brilha em construção visual e em rodar vários assistentes ao mesmo tempo.

Terminal + Extensão

Claude Code

Anthropic

Assistente de terminal. Forte para tarefas repetidas, organização de arquivos e automações. Lê as suas regras e convenções automaticamente.

Terminal + Extensão

Codex

OpenAI

Assistente de código já incluído no ChatGPT. Bom como segunda opinião, vinda de outro ecossistema, para comparar abordagens.

💡

O atalho mental

Antigravity = a sala de reunião visual. Claude Code e Codex = dois assistentes de balcão, cada um de uma "casa" diferente (Google, Anthropic, OpenAI). Você não precisa dos três — precisa do certo para a tarefa.

03
Cena 03 · Ecossistema Anthropic 3 min

Chat, Cowork e Code: três modos, um cérebro.

+

Dentro do aplicativo da Anthropic há três abas na mesma janela — não são rivais, são três modos de trabalhar com o mesmo modelo, mudando só o nível de acesso aos seus arquivos. Pense em consultor, estagiário sênior e desenvolvedor.

ModoÉ como…Mexe nos arquivos?Use para
ChatO consultor à sua frenteNão — só pensa com vocêEstratégia, ideias, raciocínio puro
CoworkO sênior segurando os autosSim, nas pastas que você liberaAnálise pesada de casos volumosos em paralelo
CodeO dev que fala terminalSim, via terminalAutomações, organização técnica de arquivos

Chat é a IA pensando ao seu lado. Cowork é a mesma IA segurando os documentos do caso junto com você — e trabalhando em várias frentes ao mesmo tempo.

⚖️

Atenção ao dado de cliente

Cowork e Code agem sobre seus arquivos. Antes de soltar IA em material sigiloso, aponte para uma pasta isolada e específica — nunca o computador inteiro. Sigilo profissional e LGPD não são detalhe técnico, são dever.

04
Cena 04 · As duas camadas 3 min

Soberania vs. Frontier: o que pode sair de casa.

+

Toda operação séria de IA tem duas camadas. Misturá-las gera ou desperdício, ou risco. A regra é simples: o que não pode sair da sua máquina vai para a camada de soberania; o que justifica o melhor modelo do mundo vai para a frontier.

Frontier · Nuvem

Modelos de ponta

Raciocínio máximo, fora de casa
  • Os modelos mais capazes do mercado
  • Análise jurídica pesada, pareceres, estratégia
  • Dado trafega pelo provedor sob seus termos
Soberania · Local

Modelos abertos na sua máquina

Dado nunca sai de casa
  • Modelos open source rodando localmente
  • Triagem, classificação, pré-análise sensível
  • Ideal para o que não pode sair por LGPD
🛡️

A verdade sem marketing

Modelo aberto rodando em computador comum não substitui um modelo de ponta para análise complexa — está em outra liga de raciocínio. A camada local é laboratório e cofre de dado sensível; a frontier é a produção pesada. Quem vende o local como substituto da nuvem está vendendo ilusão.

Cena 05 · A régua 2 min

Qual modelo, qual ferramenta, qual tarefa.

+

A régua que transforma teoria em decisão do dia a dia. Regra de ouro: proteja o melhor modelo para o que só ele faz bem. Não gaste o mais caro em tarefa boba, nem mande tarefa séria para o mais simples.

TarefaCamadaOnde fazer
Parecer, tese, raciocínio jurídico densoFrontier topChat
Análise pesada de caso volumoso em paraleloFrontier topCowork
Reescrita, formatação, ajuste de tomFrontier médioChat ou IDE
Automação repetida, organização de arquivosFrontier médioClaude Code
Construir algo visual vendo renderizarIDE visualAntigravity
Triagem em massa, dado sensível internoSoberaniaModelo local
Segunda opinião sobre uma abordagemOutro ecossistemaCodex

Leve um prompt na bagagem

Um ponto de partida testado para pedir trabalho sério a qualquer um desses assistentes. Copie e adapte.

Prompt · Tarefa profissional 
Trate isto como trabalho profissional, não resposta rápida.

Contexto: [explique o cenário]
Objetivo: [o que precisa ser produzido ou decidido]
Material: [arquivos, dados ou premissas disponíveis]
Critérios: clareza, verificabilidade, riscos, próximos passos.

Antes de responder, monte um plano curto.
Depois entregue a versão final com decisões, riscos e recomendação prática.
